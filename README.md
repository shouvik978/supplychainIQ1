SupplyChainIQ

AI-Powered Inventory & Supply Chain Intelligence

SupplyChainIQ is a Python-based inventory management and supply chain decision-support prototype.

It analyses warehouse stock, historical sales and supplier information to generate procurement recommendations.

🎯 Problem Statement

Businesses face challenges such as unexpected stock shortages, delayed deliveries and inefficient inventory management.

💡 Our Solution

SupplyChainIQ helps businesses make data-driven inventory decisions through automated analysis.

🚀 Key Features

Inventory Monitoring
Historical Sales Analysis
Stockout Risk Detection
Supplier Comparison
Automatic Reorder Calculation
Procurement Recommendation
Interactive Web Dashboard
🛠️ Technologies Used

Python
Streamlit
Pandas
GitHub
⚙️ How to Run

Install dependencies:

python -m pip install streamlit pandas

Run the Python agent:

python main.py

Run the dashboard:

python -m streamlit run app.py

Open the local URL shown in your terminal.
